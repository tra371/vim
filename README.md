# My Vim Configuration

My personal Vim configuration for development, focused on a lightweight, keyboard-driven workflow.

The configuration includes:

- Modular Vimscript configuration
- TypeScript, JavaScript and Python language-server support
- Fuzzy finding with fzf
- Tokyo Night colorscheme
- Lightline status bar

## Installation

The configuration is loaded from `~/.vim/vimrc` through the main `~/.vimrc` file.

Plugins are managed through a custom Vimscript function.
